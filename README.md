# calc-zb-lua
**calc-zb-lua** is a simple and basic calculator written in **Lua**. You type in the name of an operation, the program prompts you for the value of **two** operands and prints the evaluated result. _The calculator can only take in two operands._
## Supported operations:
- addition
- subtraction
- multiplication
- division
- integer division
- modulo
- exponentiation
>[!TIP]
>The README is not updated as frequently. Check [c_list.txt](c_list.txt) for the full updated list.

## Running the program:
>[!NOTE]
>You must have the Lua interpreter installed on your machine to run this program. You can find it at https://www.lua.org/download.html

- Run the program with `lua main.lua`
